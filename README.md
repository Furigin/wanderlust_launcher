WANDERLUST LAUNCHER
===================

Кастомный лаунчер Minecraft для проекта Wanderlust.
Ставит и запускает игру: сам скачивает Java, NeoForge, все моды,
сборки и держит их в актуальном состоянии. Игроку не нужно ставить ничего
вручную — только ввести ник и нажать «Играть».

СБОРКИ
------
- Wanderlust Create     — сборка вокруг мода Create, Minecraft 1.21.1.
- Wanderlust Stray Souls — авторская сборка со своими модами и приколами, Minecraft 26.2 (скоро).

ВОЗМОЖНОСТИ
-----------
- Выбор сборки на стартовом экране.
- Автозагрузка и обновление модов: при каждом запуске лаунчер
  сам докачивает новые моды, обновляет изменённые и убирает лишние.
- Самообновление лаунчера: новая версия скачивается и ставится автоматически.

КАК ПОЛЬЗОВАТЬСЯ
----------------
1. Скачать и запустить лаунчер.
2. Выбрать сборку.
3. Ввести ник.
4. Нажать «Играть» — дождаться загрузки, игра запустится сама.

Требования: Windows 10/11 (x64). Всё остальное лаунчер поставит сам.

О ЧЁМ ЭТОТ РЕПОЗИТОРИЙ
---------------------
Здесь раздаётся всё, что нужно лаунчеру:
  - manifest.json         — описание сборок, версий и ссылок (читается лаунчером);
  - <сборка>/pack.toml    — паки модов в формате packwiz;
  - релизы (Releases)     — сам исполняемый файл лаунчера для самообновления.
  - custom-mods/          — моды, которых нет на Modrinth и CurseForge;
  - mod-src/              — исходники своих модов;
  - scripts/              — вспомогательные скрипты.

СВОЙ МОД В СБОРКУ
-----------------
Для мода, которого нет на Modrinth и CurseForge (свой, пропатченный,
снятый с чужого сайта):

  python scripts/add-custom-mod.py путь/к/моду.jar [both|client|server]

Скрипт положит jar в custom-mods/, посчитает sha256, создаст запись
wanderlust-create/mods/<modid>.pw.toml со ссылкой на GitHub Pages и обновит
индекс пака. Останется закоммитить и запушить — лаунчер игроков подтянет мод
сам при следующем запуске.

Третий аргумент — кому мод нужен: both (по умолчанию), client или server.
Серверные моды игрокам не скачиваются.

Ссылка живёт по адресу
https://furigin.github.io/wanderlust_launcher/custom-mods/<имя файла>,
поэтому после push надо дать GitHub Pages минуту на выкладку.

Обновление такого мода: собрать новый jar и прогнать скрипт заново — он
пересчитает хеш и перепишет запись. Если версия в имени файла изменилась,
старый jar из custom-mods/ удалить вручную.

ПРОВЕРКА ПАКА
-------------
Если правил .pw.toml руками (мимо add-custom-mod.py), обязательно сделай
`packwiz refresh` в папке wanderlust-create — packwiz не пересчитывает индекс
сам, и без этого у игроков установка падает с «Invalid mod file hash».

Проверить, что всё сходится:

  python scripts/check-pack.py            # локально
  python scripts/check-pack.py --online   # ещё и то, что реально раздаётся

ОБНОВЛЕНИЕ ЛАУНЧЕРА
-------------------
  python scripts/release-launcher.py            # версия +1
  python scripts/release-launcher.py 0.3.0      # конкретная

Скрипт поднимает версию, гоняет тесты, собирает exe, кладёт его в download/,
прописывает версию и sha256 в manifest.json, коммитит и пушит. Через минуту
Cloudflare разложит файлы, и лаунчеры обновятся сами при следующем запуске.
