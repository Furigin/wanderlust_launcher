# Wanderlust Restart

Перезапускает сервер по расписанию, но не молча: перед перезапуском в чате
открывается голосование с кнопками. Если против набралось не меньше заданной
доли онлайна — перезапуск переносится.

**Важно:** мод только *гасит* сервер. Поднять его обратно должна панель
хостинга или скрипт-обёртка вокруг запуска. Если поднимать некому — сервер
просто выключится и не встанет.

Как проверить свою панель за минуту: напиши в консоль `stop` и посмотри,
поднимется ли сервер сам.

* Поднялся — всё готово, мод сработает так же.
* Не поднялся, но в панели есть «restart on crash» / «перезапуск при падении» —
  поставь в конфиге `exitCode` ненулевым (например `1`). Тогда штатный
  перезапуск будет выглядеть для панели падением, и она поднимет сервер.
  Миру это ничем не грозит: код выставляется уже после того, как всё сохранено
  и сервер остановлен.
* Ни того, ни другого — нужна обёртка вокруг запуска, например
  `while true; do java @user_jvm_args.txt ... nogui; sleep 5; done`.

## Как это выглядит для игроков

За `voteMinutes` до перезапуска в чат приходит:

```
──────────────────────────────────────────────
Плановый перезапуск через 5 мин.
Если против будет хотя бы 50% онлайна — перезапуск отменится на 60 мин.
   [ ЗА ]   [ ПРОТИВ ]
   за 0 · против 0 из 7 (ещё 4 — и перезапуска не будет)
──────────────────────────────────────────────
```

Кнопки кликабельные. Дальше каждую минуту приходит короткое напоминание с
текущим счётом и теми же кнопками.

Последние 10 секунд — обратный отсчёт титрами на весь экран: крупная красная
цифра, под ней «Перезапуск», каждую секунду звук (тон повышается к нулю).
В момент самого перезапуска — «ПЕРЕЗАПУСК» во весь экран и удар колокола.

Переголосовать можно сколько угодно раз — учитывается последний голос.

Отмена срабатывает **сразу**, как только «против» набралось: сообщение об
отмене приходит в ту же секунду, отсчёт не идёт. Ждать конца таймера не нужно.

## Порог

Считается **от числа игроков онлайн**, а не от числа проголосовавших: молчание
не считается голосом против. При 10 игроках онлайн и пороге 50% нужно 5 голосов
против, чтобы перезапуск отменился.

Если на сервере никого нет, порог не берётся никогда — сервер перезапускается.

Голоса считаются только у тех, кто **сейчас на сервере**. Иначе вышедший игрок
продолжал бы держать свой голос против, а онлайн при этом уменьшался — и порог
набирался бы сам собой, без единого нового голоса.

## Команды

| Команда | Кому | Что делает |
|---|---|---|
| `/wlrestart` или `/wlrestart status` | всем | сколько осталось до перезапуска |
| `/restartvote yes` / `no` | всем | голос (её же дёргают кнопки) |
| `/wlrestart now` | оператор (3) | перезапустить немедленно |
| `/wlrestart postpone` | оператор (3) | отложить на `postponeMinutes` |
| `/wlrestart reload` | оператор (3) | перечитать конфиг |

В консоли сервера команды пишутся **без слэша**: `wlrestart now`, `wlrestart status`.

## Конфиг

`config/wlrestart.json`, создаётся при первом запуске.

| Поле | По умолчанию | Что значит |
|---|---|---|
| `enabled` | `true` | выключает автоперезапуск (`/wlrestart now` продолжает работать) |
| `intervalHours` | `4.0` | через сколько часов после старта перезапускаться |
| `voteMinutes` | `5` | за сколько минут до перезапуска открыть голосование |
| `vetoPercent` | `50` | какая доля онлайна должна быть против |
| `postponeMinutes` | `60` | на сколько переносить при отказе |
| `skipVoteIfEmpty` | `true` | если никого нет — перезапускаться сразу |
| `announceMinutes` | `[60, 30, 15]` | ранние предупреждения без кнопок |
| `kickMessage` | … | текст на экране отключения |
| `exitCode` | `0` | с каким кодом завершить процесс (см. выше про панель) |

Отсчёт начинается заново при каждом старте сервера. То есть при
`intervalHours = 4` сервер живёт 4 часа с момента запуска, а не по часам суток.

## Сборка

Gradle не нужен: NeoForge 1.21.1 в проде использует читаемые Mojang-имена,
поэтому мод собирается обычным `javac` по jar-ам установленного сервера.

```bash
./build.sh                       # сервер из C:\Users\rusla\Desktop\сервак, JDK 21
./build.sh /путь/к/серверу /путь/к/jdk21
```

Результат — `build/wlrestart-1.0.0.jar`.

Единственная тонкость: в `libraries` рядом с `server-…-srg.jar` (читаемые
имена) лежат `slim`/`unpacked`/`extra` — там имена обфусцированы, и если
javac возьмёт их первыми, весь API «пропадёт». `build.sh` их отбрасывает.
